# React каталог звёздных систем

Ветка допзадания по РИП. Каталог загружает страницы с сервера, фильтрует по дате получения и показывает общее число совпадений. Лента получает карточки из подборки Redis.

1. Запустите [FastAPI для допзаданий](https://github.com/qcvnnn/star_lists/tree/feature/rip-extras) на localhost:8000.
2. Выполните `npm ci`, затем `npm run dev`.
3. В каталоге введите дату 14.01.2025 и переключите страницу.

Обычная сборка сохраняет автономный режим. Для сборки с подключением к API задайте `VITE_LIVE_API=true`.
